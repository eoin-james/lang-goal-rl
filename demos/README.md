# Demo clips

Clips 1-3 (stage 3) generated by
`experiments/03_language_goal_projection/make_demos.py` from
`experiments/03_language_goal_projection/checkpoints/seed_0.zip` (SAC+HER
policy, literal 1.000 eval success rate, unchanged across all stage-3
attempts 1-4). Clips 4-7 (stages 1, 2, 4, 5) generated by each stage's own
`make_demo.py`, added later to cover the stages that previously had no
visual proof at all — see their entries below for checkpoints/instructions
used. Every clip's success/fail label below is the real,
`info["is_success"]`-grounded outcome of the exact recorded episode
(`lang_goal_rl.episode_recording.record_episode` for clips 1-6,
`record_episode_with_goal_switch` for clip 7) — never assumed.

## 1. `01_baseline_success.gif`
**Literal-goal mode** — no override, the policy sees whatever
`GoalEmbeddingExtractor` normally computes from the env's real
`desired_goal`. First eval seed tried (seed 1000) succeeded.
**Result: success (1/1 seed tried).** Consistent with this checkpoint's
measured 1.000 literal-goal eval success rate over 50 episodes.

## 2. `02_broken_language_failure.gif`
**Attempt 1's broken projection** (pre-scale-fix InfoNCE checkpoint,
`artifacts/language_goal_projection.pt`) overriding the policy's desired-goal
input for the instruction *"reach up high"*. Ground truth is a real xyz goal
sampled from the "reach up high" region; one episode recorded, no
cherry-picking (the point of this clip is the actual failure mode, not a
best-case draw).
**Result: failure (1/1 seed tried, seed 9000).** Consistent with attempt 1's
measured aggregate language-goal success rate of 0.002 across 3 seeds x 14
instructions x 50 episodes (near-total failure) — this projection's output
norm sat 5-10x outside the frozen encoder's real operating range.

## 3. `03_language_goal_result.gif`
**Attempt 3's fixed-centroid-regression projection**
(`artifacts/language_goal_projection_v3.pt`) overriding the policy's
desired-goal input for the same instruction, *"reach up high"* — but now
evaluated under **attempt 4's corrected ground-truth protocol**
(`train.compute_region_centroid`): a single fixed xyz centroid for the
region, reused for every attempt, instead of clip 2's per-attempt resampled
random point. Attempt 3's own eval had measured only a 0.120 success rate
for this exact instruction against the old (resampled-point) ground truth;
the stage-3 reviewer diagnosed that ground-truth protocol itself — not the
projection — as the actual defect, since the policy only ever saw one fixed
embedding the whole time. Attempt 4's fix realigned the ground truth with
what that embedding represents, and re-measured 1.000 across all 3 seeds x
50 episodes for this instruction (and every other one).
**Result: success on the 1st of 1 seed tried, seed 9000.** No searching was
needed — the first attempt succeeded, consistent with attempt 4's measured
1.000 aggregate language-goal success rate (42/42 seed x instruction
samples, 3 seeds x 14 instructions x 50 episodes each), matching the 1.000
stage-2 literal-goal baseline the proof gate requires. This is now a
reliable success, not a lucky draw — contrast with the pre-fix framing this
same clip carried under attempt 3 (a 1-in-7 draw, kept here in git history
for the record).

## 4. `04_stage1_literal_baseline.gif`

**Stage 1 — literal xyz goal, no learned embedding, no language at all.**
Generated by `experiments/01_uvfa_her_baseline/make_demo.py` from
`checkpoints/seed_0.zip`, one of stage 1's 8 healthy seeds (seeds 2 and 7 are
deliberately excluded — `experiments/01_uvfa_her_baseline/report.md`'s Pass 2
reviewer verdict documents both as showing the SAC deterministic-eval-
collapse signature, a known algorithm-level fragility, not a defect in
goal-conditioning itself). No override: `record_episode` is called with
`goal_embedding_override=None`, so the policy sees exactly what
`env.reset()` samples as `desired_goal`. First held-out eval seed tried
(seed 1000, matching `train.py`'s `evaluate()` seed range) succeeded.
**Result: success (1/1 seed tried).** Consistent with seed 0's own measured
1.000 eval success rate over 50 episodes (`report.md`'s Result summary
table) and with 8/10 seeds overall hitting a perfect 1.000.

## 5. `05_stage2_embedding_baseline.gif`

**Stage 2 — learned 16-dim goal-embedding representation (contrastive
pretraining), still no language.** Generated by
`experiments/02_contrastive_goal_embedding/make_demo.py`. Stage 2 never
persisted an RL checkpoint to disk (`train.py`'s `main` only prints the eval
success rate, no `model.save(...)` anywhere — confirmed by reading the whole
file), so this clip reuses `experiments/03_language_goal_projection/
checkpoints/seed_0.zip` instead of retraining. This substitution was
independently verified, not assumed: stage 3's `build_model` is
byte-for-byte the same SAC/HER hyperparameters and `GoalEmbeddingExtractor`
config as stage 2's own `build_model`, and it loads stage 2's *exact*
pretrained encoder weights (`02_contrastive_goal_embedding/artifacts/
goal_encoder.pt`, unchanged) — stage 3's `train.py` even runs this checkpoint
through the literal-goal protocol first, specifically to confirm it
reproduces stage 2's result before touching anything language-related. This
is not literally stage 2's original seed-0 run (those weights were never
saved to reuse), but a fresh run of the identical protocol — since stage 2's
proof gate is about whether that protocol works, not about one arbitrary
seed's weights, this is a faithful stand-in. Recorded in literal-goal mode
(no override): the policy sees the env's real `desired_goal` run through
`GoalEmbeddingExtractor` → stage 2's frozen `GoalEncoder`, exactly what stage
2's proof gate tests. First held-out eval seed tried (seed 1000, same range
as stage 1/2's `evaluate()`) succeeded.
**Result: success (1/1 seed tried).** Consistent with stage 2's measured
10/10 seeds ≥0.98 (median/mode 1.000, `experiments/02_contrastive_goal_embedding/report.md`).

## 6. `06_stage4_open_vocabulary_result.gif`

**Stage 4 — a live English sentence, never used to train anything, actually
steering the robot.** Generated by
`experiments/04_open_vocabulary/make_demo.py` using
`src/lang_goal_rl/live_goal_controller.py`'s `LiveGoalController` (k=1
nearest-neighbor lookup over the 84-sentence combined vocabulary — stage 4's
final, passing mechanism) to convert an instruction into a goal embedding,
then `03_language_goal_projection/checkpoints/seed_0.zip` (same checkpoint
every stage-3/4 eval uses) to act on it. Stage 4's own `report.md` says
outright that no existing chart captures this passing result — every chart
on file was made for an earlier, failed attempt. This is that missing proof.

Two held-out instructions were tried, in this order, and both real outcomes
are reported — not cherry-picked:

1. **"raise your arm as high as it will go"** (region "reach up high",
   `held_out_paraphrases.HELD_OUT_PARAPHRASES`) — the task brief's own
   suggested example. Reading `report.md`'s Attempt 4 per-instruction tables
   directly (rather than assuming them) shows this *specific* phrase is
   misclassified under k=1 lookup (nearest region comes back "reach down
   low") and scores a documented 0.000 RL success on all 3 of stage 4's
   checkpoints — a deterministic outcome (fixed goal-embedding + fixed
   policy), not a per-seed draw, so retrying seeds would not have changed it.
   **Recorded outcome: failure**, exactly as the report predicts.
2. **"extend upward toward the ceiling"** — a second held-out phrase from
   the same "reach up high" region, which the same report table documents as
   correctly classified under k=1 and a reliable 1.000 RL success on all 3
   checkpoints. **Recorded outcome: success.** This is the clip saved to
   `06_stage4_open_vocabulary_result.gif`.

**Result: success on the 2nd of 2 held-out instructions tried (seed 9000
both times).** The 1st instruction's failure is genuine and expected, not a
bug — both outcomes were independently confirmed by actually running the
pipeline, not taken from the report table on faith. Consistent with attempt
4's aggregate k=1 held-out result (mean 0.571, median 1.000, 24/42 nonzero
samples — a binary, per-instruction pattern of 8/14 phrases always
succeeding and 6/14 always failing across all 3 checkpoints, not a smooth
quality gradient), and with the reviewer's PASS verdict noting the k=1
mechanism "never deviates from a known-good point" for phrases it classifies
correctly.

## 7. `07_stage5_midepisode_switch.gif`

**Stage 5 — the robot's target changes partway through the episode, with no
reset, and it still gets there.** Generated by
`experiments/05_midepisode_regoal/make_demo.py` using
`lang_goal_rl.episode_recording.record_episode_with_goal_switch` against
`experiments/01_uvfa_her_baseline/checkpoints/seed_0.zip` — the same healthy
seed clip 4 uses (seeds 2 and 7 excluded for the same documented SAC
deterministic-eval-collapse reason). Literal-xyz mode throughout (no
embedding override): the policy sees the env's real `desired_goal` in both
phases, matching stage 5's own scope of testing the re-goaling mechanism
itself, not the embedding layer stages 2-4 cover.

Goal pair: a point sampled from the "reach left" region, switched at step 20
of a 50-step episode to a point sampled from the "reach up high" region —
two regions picked for visual clarity (the two goals are unmistakably
different on screen), one of the four switch points (10/20/30/40)
`run_regoal_eval.py` actually measured. Success is judged against the *new*
("reach up high") goal only — any success against the old goal before the
switch never counts.

**Result: success on the 1st of 3 attempts tried (seed 10000 — the exact
`base_seed` `run_regoal_eval.py` itself uses for switch_step=20's first
episode).** This is the visual counterpart to stage 5's own measured result:
across 8/10 healthy seeds, the swap condition equalled the budget-matched
baseline equalled the full-budget reference — 1.000 == 1.000 == 1.000 — at
every switch_step tested (`experiments/05_midepisode_regoal/report.md`). The
10-seed statistical result already showed the re-goaling mechanism adds no
measurable extra difficulty; this clip is that same finding made visible —
one real episode where the robot is given a completely different mid-episode
target and still reaches it.
